NSW Suburb Environmental Risk Orchestrator

Generate 7-day erosion & sediment control plus dust risk guidance for your active suburbs in New South Wales.

Overview

The orchestrator is an R script (sustainability/nsw_risk_orchestrator.R) that geocodes suburbs, locates their nearest Bureau of Meteorology forecast and observation stations, and combines the results with customised scoring formulas to produce actionable risk collateral.

Outputs include per-suburb CSV schedules, trend charts, a Leaflet map, and an iCalendar feed for high-risk days—ready for CTRL Environmental workflows.

Prerequisites

  • R 4.1 or newer.
  • Internet access (for package installation, geocoding, and BoM data calls).
  • A CSV named suburbs.csv (or another file specified via --input) containing at least a suburb column.

Optional columns:

  • soil — overrides the default soil type (LOAM).
  • latitude / longitude — bypasses the geocoder if coordinates are already known.

Running the workflow

  1. Place your suburbs.csv in the repository root (or provide an absolute path).
  2. From a shell, execute:
Rscript sustainability/nsw_risk_orchestrator.R \
  --input suburbs.csv \
  --out risk_out \
  --state NSW \
  --threshold 60 \
  --default-soil LOAM

All options are optional; values shown above are the defaults. The script will install required CRAN packages if missing (using the Posit CRAN mirror).

Key outputs

  • plan_<suburb>.csv — tabular forecast with ESC/Dust scores, rain/wind context, and suggested actions.
  • trend_<suburb>.png — seven-day chart highlighting thresholds, streaks, and change points.
  • map.html — Leaflet map coloured by current day risk, including popup action prompts.
  • High-Risk.ics — calendar entries for days meeting the threshold (default: score ≥ 60).

Files are written to the output directory chosen via --out (created automatically if it does not exist).

Scoring summary

ESC (Erosion & Sediment Control)

Rainfall, wind, and peak temperature are weighted (58% / 28% / 14%) and adjusted by the soil susceptibility factor. Caps prevent runaway scores while still prioritising high-impact weather.

Dust Risk

Dryness bonuses reward extended dry spells, while wind over 20 km/h and hot temperatures accelerate dust uplift. Recent rainfall (3 & 7-day windows) dampens the score.

Action statements are generated automatically based on combined ESC/Dust severities.

Data sources

  • Geocoding: tidygeocoder with the OpenStreetMap / Nominatim service (bias set via --state).
  • Forecasts: Australian Bureau of Meteorology "precis" forecasts via the bomrang::get_precis_forecast() API.
  • Rainfall history: Bureau of Meteorology daily observations fetched through bomrang::get_historical().

Ensure downstream use complies with the respective provider terms of use (OpenStreetMap Nominatim usage policy and the Bureau of Meteorology data licence).

Troubleshooting

  • Geocoding failures: Ensure suburb names are valid NSW localities. You can supply coordinates directly to skip geocoding.
  • BoM errors: Intermittent BoM outages can produce warnings; affected stations are skipped so other suburbs continue processing.
  • Package installation prompts: Run the script with write access to your R library path or set R_LIBS_USER accordingly.
